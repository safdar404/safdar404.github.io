Workflow 01

New Client Requests

Tested · Active

Every time a new client request lands in a Google Sheet (e.g. from a web form), the client gets an instant thank-you email, is saved to Google Contacts, and I receive a summary notification.

📄Google Sheets Triggerrow added · every minute
→
✉️Thank-you emailGmail · send
→
👤Add to ContactsGoogle Contacts · create
→
🔔Notify meGmail · send

What it does

  • Polls the sheet for new rows (name, email, phone, description)
  • Personalised reply to the client by name
  • Splits full name into given / family name for the contact
  • Sends an internal alert with the request details

Tested

  • Multiple successful end-to-end runs on n8n Cloud
  • Published (active) on the Google Sheets trigger

Workflow 02

AI Agent Email Assistant

Tested · Active

A chat-driven AI agent. Ask it in plain English to email a customer by name — it looks the customer up in a Google Sheet database, writes a personalised email from your message and sends it through Gmail.

💬Chat messageChat Trigger
→
🤖AI Agenttool calling
uses ↳
✨OpenAI gpt-4o-mini
🧠Simple Memory
📄Get CustomersSheets tool
✉️Send EmailGmail tool · $fromAI()

What it does

  • Understands the request: who to email and what to say
  • Finds the customer's address in the sheet (Full Name, Email, Phone)
  • Never guesses an address — asks if no match or several matches
  • Composes and sends the email, then confirms recipient and subject

Tested

  • Prompt: “Send an email to Suleman Safdar thanking him for his order…”
  • Agent called Get Customers (4 rows) → Send Email (1 sent)
  • Small-talk messages correctly answered without tool calls

Workflow 03

Motivational Quote Generator

Tested · Active

Every morning at 7 AM (Asia/Karachi) an LLM writes a fresh motivational quote with a one-line tip, and every recipient in a Google Sheet gets a personalised “Good morning {name}” email.

⏰Every day 7 AMSchedule + manual test
→
✨Generate QuoteBasic LLM Chain · gpt-4o-mini
→
📄Get RecipientsGoogle Sheets · read
→
✉️Send Quote EmailGmail · one per recipient

What it does

  • One quote generated per day, shared across all recipients
  • Recipient list managed in a Google Sheet (Name, Email)
  • Manual trigger kept for testing alongside the schedule
  • Dated subject line: “Your Daily Motivation – {date}”

Tested

  • Manual runs: all nodes green, email delivered
  • Live schedule test: fired automatically with no clicks and delivered the email
