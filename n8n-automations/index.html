Workflow 04

Patient Appointment Reminder & No-Show Recovery

Tested · Active

A daily clinic automation. Every morning it reads the Appointments sheet, finds tomorrow’s patients, and reminds each one on the channel they consented to — WhatsApp or email. Invalid records are logged, not dropped, and the team gets one Slack summary per run.

What it does

  • Code node filters to tomorrow, skips cancelled or already-reminded rows and validates consent, phone and email
  • Routes each patient to WhatsApp or Gmail and pre-renders both message bodies
  • Marks the row reminder_sent = YES so a re-run never double-messages a patient
  • Patients with missing consent or bad contact details go to an Exceptions sheet

Tested

  • Successful runs on n8n Cloud, both manual and on the 09:00 schedule
  • Published (active) on the daily Schedule Trigger

Workflow 05

Resume AI Analyzer (Web Form)

Tested · Active

A candidate-screening pipeline behind a public n8n form. Applicants upload a PDF CV; the workflow stores it in Google Drive, extracts the text, has an AI agent score the candidate and logs the result to a sheet — then emails a shortlist report or a polite thank-you depending on the score.

What it does

  • Form collects name, email and CV (PDF) and saves the file to Google Drive
  • Information Extractor pulls structured fields (name, email, phone, skills…) from the CV
  • AI Agent writes an evaluation with a 1–5 score; a Code node parses it
  • Score ≥ 4 → recruiter report + shortlist email; otherwise a thank-you email

Tested

  • Successful end-to-end runs via the live form (webhook) and manual tests
  • Published (active) on the Form Trigger

Workflow 07

Document RAG Assistant

Tested · Active

Retrieval-augmented Q&A over your own documents. Drop a file into a Google Drive folder and it is chunked, embedded and indexed automatically; then chat with an AI agent that answers only from those documents.

What it does

  • Drive Trigger picks up new files in a watched folder
  • Default Data Loader + recursive text splitter (with overlap) chunk the file, tagged with file name and ID
  • OpenAI embeddings stored in a vector store
  • RAG Agent (GPT-4o, low temperature, chat memory) uses the store as a search tool and refuses to answer beyond the documents

Tested

  • Successful ingestion and chat runs on n8n Cloud
