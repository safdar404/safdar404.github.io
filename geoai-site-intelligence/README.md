# GeoAI Site Intelligence Suite

**AI/ML + GeoAI + GIS + Spatial Decision Support**

A portfolio-grade three-application GeoAI suite by **Muhammad Safdar**, designed to demonstrate how spatial data, remote sensing, machine learning, multi-criteria decision analysis (MCDA) and interactive web mapping can support real-world site-selection and resilience decisions.

> **Important:** These applications are decision-support prototypes. They demonstrate analytical workflows and interface design; results should be validated with authoritative local datasets, engineering studies and domain experts before operational use.

## 📐 Decision model

The suite is structured around a weighted suitability concept:

`Suitability Score = Σ (normalized criterion × criterion weight)`

Typical criteria can include:

- Accessibility / infrastructure proximity
- Terrain and elevation
- Flood hazard or drainage context
- Land-use / land-cover compatibility
- Environmental constraints
- Distance to utilities or transport networks
- Resource or exposure indicators

Weights should be treated as scenario parameters rather than universal truths. A production implementation should document data provenance, spatial resolution, normalization methods, uncertainty and validation results.

## 📊 Expected outputs

The applications are designed to communicate results as:

1. **Suitability maps** — spatial patterns of relative suitability.
2. **Ranked candidate sites** — prioritized locations/zones for further investigation.
3. **Factor breakdowns** — visibility into why a candidate scores well or poorly.
4. **Scenario comparisons** — assessment of how different priorities change rankings.
5. **Decision evidence** — map layers and criteria that can be reviewed before action.
